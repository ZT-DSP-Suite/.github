# Contributing

## Before you start

1. Read the specification in `ZT-DSP-docs`.
2. Read `CONTRIBUTING.md` and `LICENSING.md` in the same repository. Those files carry the CLA.
3. Check the four gates in `DEV-GUIDE.md` of the same repository.

## How to submit

1. Sign every commit: `git commit -s`.
2. Add a CLA line to `CONTRIBUTORS.md` in the same commit.
3. Open a pull request against the repository you changed.

## What a pull request must carry

| Item | Why |
|---|---|
| All four gates green | A change is done only when they pass |
| Signed-off-by on every commit | The organisation requires DCO sign-off |
| No change to frozen wire field names | Interoperability depends on them |
