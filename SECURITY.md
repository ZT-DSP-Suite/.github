# Security Policy

## How to report a vulnerability

Open a private security advisory on the affected repository, under the Security tab.
Do not open a public issue.

## What to include

| Item | Note |
|---|---|
| Affected repository and commit | Exact identification |
| Steps to reproduce | A command sequence or a packet trace |
| Impact | What an attacker gains |

## What happens next

1. Acknowledgement within seven days.
2. A fix, or a written rejection with reasons.
3. Credit in the release notes, unless you ask otherwise.
