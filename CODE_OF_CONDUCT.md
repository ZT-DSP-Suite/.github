# Code of Conduct

## Scope

Issues, pull requests, discussions and reviews in this organisation.

## Expected

| Do | Do not |
|---|---|
| Argue about the code | Attack the person |
| Quote the line you disagree with | Dismiss a report without reading it |
| Say what evidence would change your mind | Demand credentials or private data |

## Enforcement

Report privately through a security advisory. The maintainer removes the content or blocks the account.
